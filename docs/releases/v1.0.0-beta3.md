# LunexSU v1.0.0 Beta3

## 中文更新日志

Beta3 整合内置 Zygisk、可选超级密钥及上游一次性脚本和模块热安装功能，不替换此前发布版本。

### 新功能与调整

- 内置 Zygisk 默认关闭，启用后默认使用 ReZygisk，可手动切换 NeoZygisk；可选启用 ZygiskNextNext，提供 Zygisk Next API 加载支持。后者不是第三个标准 Zygisk 后端，也不是闭源 ZygiskNext。
- 设置卡片、后端选择、附加开关和重启对话框适配 Material、MIUIX 及 FinaSU 主题；总开关关闭时附加开关置灰。每次成功变更均提示重启后生效，不做热切换。
- 检测外部实现冲突，安装失败时隔离残留并尝试回滚；内置组件从普通模块列表隐藏。旧测试版内置 Vex 用户需先关闭并重启，再启用 Re，避免遗留启动脚本。
- 安装/修补 Core 时可选额外超级密钥验证，默认关闭。启用后仍须通过 Manager 包名和签名校验；认证按完整 UID 保持至重启或身份失效，而非每次操作都询问。
- 无 Manager 权限时显示密钥输入入口；未安装 Core 或验证失败统一提示“可能未安装或密码错误”。忘记密钥需重新刷入未配置密钥或配置新密钥的匹配 Core。
- 主题内置音乐默认暂停，需用户手动播放；不再随启动或切换主题自动播放。
- 同步 KernelSU 上游的一次性脚本、参数/源码预览及运行记录，以及模块选择性热安装和对应文档。挂载变更不保证即时生效，热安装也不能替代所有场景的重启。
- 修复热安装后指向模块内文件的绝对符号链接失效；修复脚本启动或清理异常导致页面停留在运行状态、无法退出的问题，并增加回归测试。

### 验证、下载与限制

- 合并后本地 289 项 JVM 测试、干净 Release 构建、Android 测试 APK 编译和授权/回滚主机测试通过；云端检查及全架构发布构建在发布前完成验证。
- 提供 28 个附件：Manager APK、16 个 LKM（8 个 KMI × arm64/x86_64）、8 个平台的 ksud，以及 3 个架构的 ksuinit。APK 保持原包名和签名，可覆盖安装 Beta2；新功能请配套本版本 Core。
- 内置组件固定为 ReZygisk v1.0.0、NeoZygisk v2.4、ZygiskNextNext v1.8.3，附许可证和对应源码链接，详见仓库 `docs/lunexsu-zygisk.md`。
- 内置 Zygisk 不支持 riscv64；Neo 不注入 64 位系统中的 32 位应用。不能保证所有模块、厂商 ROM、命名空间及挂载组合兼容。
- 本次没有新增真机验证，测试 APK 仅编译、未在设备上执行。仍为预发布版本，请先备份并准备救援方式；主题音效仍不支持，其他已知限制不变。

## English changelog

Beta3 combines built-in Zygisk, optional Manager superkey authentication, and upstream one-shot scripts and hot module installation. Earlier releases remain unchanged.

### Features and changes

- Built-in Zygisk defaults to off. Enabling selects ReZygisk, with NeoZygisk available manually. Optional ZygiskNextNext adds Zygisk Next API loading support; it is neither a third standard Zygisk backend nor the closed-source ZygiskNext distribution.
- The Settings card, backend selector, companion switch and reboot dialog support Material, MIUIX and FinaSU themes. The companion switch is disabled when built-in Zygisk is off. Every successful change requests a reboot; no live switching is attempted.
- Detect external implementation conflicts, quarantine failed staging and attempt rollback. Owned components are hidden from the regular module list. Users of earlier built-in Vex test builds must disable it and reboot before enabling Re so old startup hooks can be removed.
- Core installation/patching offers an optional superkey, off by default. Manager package and certificate checks remain mandatory. Authentication is scoped to the full UID until reboot or identity invalidation, not prompted for every operation.
- Show the key entry whenever Manager privileges are unavailable. Missing Core and failed authentication use the same generic error. A forgotten key requires reflashing a matching Core with the option disabled or a new key configured.
- Theme music starts paused and requires manual playback instead of starting automatically on launch or theme changes.
- Sync upstream KernelSU one-shot scripts, parameter/source previews, run history, selective hot module installation and documentation. Mount changes may still require reboot; hot installation does not eliminate reboot requirements in all cases.
- Fix absolute symlinks to in-module scripts becoming invalid after hot installation. Ensure failed script execution and cleanup leave the running state and release resources, with regression coverage.

### Validation, downloads and limitations

- The combined tree passed 289 local JVM tests, a clean Release build, Android test APK compilation and authorization/rollback host tests. Cloud checks and the complete release matrix are verified before publication.
- Include 28 assets: the Manager APK, 16 LKMs (8 KMIs across arm64/x86_64), ksud for 8 targets and ksuinit for 3 architectures. The APK retains its package and signing certificate and can update Beta2. Use the matching Core for the new features.
- Pin ReZygisk v1.0.0, NeoZygisk v2.4 and ZygiskNextNext v1.8.3, with license texts and corresponding source links documented in `docs/lunexsu-zygisk.md`.
- Built-in Zygisk does not support riscv64. Neo does not inject 32-bit applications on 64-bit systems. Compatibility with every module, vendor ROM, namespace and mount configuration is not guaranteed.
- No additional device testing was performed. The Android test APK was compiled, not executed on a device. This remains a prerelease: back up and prepare recovery options. Theme sound effects remain unsupported; other known limitations remain unchanged.
