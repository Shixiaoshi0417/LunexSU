# LunexSU v1.0.0 Beta1

## 中文更新日志

### 新增与改进

- 首个 LunexSU Beta 发布，提供独立包名 `com.shixiaoshi0417.lunexsu` 和配套 Manager、Core、ksud 构建产物。
- Root 授权支持「本次运行 / 限时 / 永久」：本次运行可预授权，应用运行期间允许重复获取 Root，最后一个普通进程退出后撤销；撤销不强制终止已有 Root 进程。
- 支持 FinaSU FPT 主题导入及在线主题商店，保留导入确认、资源校验和不支持项目提示。
- 专用主题 UI 支持首页卡片背景、GIF、昼夜透明度与遮罩、字体、标题图片、导航图标、背景音乐、视频背景和应用语言。清除主题后恢复原先选择的 M3E / MIUIX 界面。
- 普通 M3E / MIUIX 与主题兼容逻辑隔离，保留原生导航和配色。

### 修复

- 修复禁用策略配置下授权能力识别错误，以及主题库同 ID 更新和未完成下载误展示问题。
- 修复隐藏卡片内容后出现红色色块、二级页面透出上一页内容，以及主题设置页面无法向下滚动的问题。
- 修复主题容器校验对随机 IV 的误判，并保留安全大小限制与原子应用机制。

### 上游同步

- 已合入 KernelSU `0c0fdb96`（截至本次同步时的 `main`），保留 LunexSU 授权策略与主题功能。
- 同步新的模块仓库 Registry API、下载完整性验证、本地缓存与描述展示改进。
- 同步原生模块黑名单、安装时显式选择模块屏蔽，以及 Shell Root 的 ADB 来源限制选项。
- 同步 Rust 依赖更新、启动映像相关改进及印度尼西亚语翻译更新。

### 下载与注意事项

- 普通用户安装 `LunexSU_*.apk`；LKM 请严格选择匹配设备架构和 KMI 的 `LunexSU-lkm-*.ko`。
- 附带各平台 `LunexSU-ksud-*` 和 `LunexSU-ksuinit-*`，用于对应安装或开发流程。
- 授权有效期需要配套 LunexSU Core；仅安装 Manager 无法为旧 Core 增加临时授权。
- Beta 版本请先备份原始启动映像并准备恢复方案；不要将其他 KMI 的模块刷入设备。
- 音效尚未支持，媒体格式能否播放取决于设备解码器；不保证所有 FinaSU 主题像素级一致。
- 发布前主题 UI 与设置滚动修复已由用户反馈真机通过；上游同步后的变更另经自动化构建与测试验证，不等同于覆盖所有设备的真机测试。

## English changelog

### Features and improvements

- First LunexSU Beta release, with the separate package `com.shixiaoshi0417.lunexsu` and matching Manager, Core and ksud build artifacts.
- Root authorization supports **This app run / Timed / Permanent**. A run-scoped grant can be prepared before launch, permits repeated Root requests during the run, and is revoked after the last ordinary process exits. Revocation does not forcibly terminate existing Root processes.
- FinaSU FPT imports and the online theme store retain confirmation, resource validation and explicit unsupported-feature warnings.
- The dedicated theme UI supports home card images, GIFs, day/night opacity and dimming, fonts, title images, navigation icons, background music, video backgrounds and application language. Removing a theme restores the previously selected M3E / MIUIX UI.
- Ordinary M3E / MIUIX rendering remains isolated from theme compatibility, preserving native navigation and colors.

### Fixes

- Fixed authorization capability detection with policy disabled, same-ID theme updates and incomplete downloads appearing in the library.
- Fixed solid red hidden-content cards, covered pages showing through secondary screens, and themed settings refusing downward scrolling.
- Fixed theme container validation incorrectly rejecting random IVs, while retaining bounded resource loading and atomic application.

### Upstream synchronization

- Merged KernelSU `0c0fdb96` (`main` at synchronization time), preserving LunexSU authorization policies and theme features.
- Included the new module Registry API, download integrity verification, local caching and improved description rendering.
- Included native module blacklisting, explicit opt-in for module blocking during installation, and the Shell Root ADB-origin restriction option.
- Included Rust dependency updates, boot-image improvements and Indonesian translation updates.

### Downloads and caveats

- Install `LunexSU_*.apk` for normal use. Select `LunexSU-lkm-*.ko` strictly by the device architecture and KMI.
- Platform-specific `LunexSU-ksud-*` and `LunexSU-ksuinit-*` are included for matching installation and development workflows.
- Expiring authorization requires the matching LunexSU Core; replacing only the Manager cannot add temporary grants to an older Core.
- This is a Beta. Back up the original boot image and prepare a recovery method before installation. Never flash a module built for another KMI.
- Sound effects are not supported yet. Media playback depends on device codecs; pixel-perfect compatibility with every FinaSU theme is not guaranteed.
- The user confirmed device testing of the theme UI and settings-scroll fixes before release preparation. Subsequent upstream changes are separately validated by automated builds and tests; this is not a claim of testing every device.
