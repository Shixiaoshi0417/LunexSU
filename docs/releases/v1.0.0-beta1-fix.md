# LunexSU v1.0.0 Beta1 Fix

## 中文更新日志

这是 Beta1 的主题下载修复版本，包含 PR #4，不替换或覆盖原 Beta1 发布。

### 修复

- 修复取消主题下载后立即重新下载时，旧任务覆盖新任务进度、清除新任务状态或错误发布文件的竞态问题。
- 为每个下载任务独立管理临时文件及任务身份，旧任务只能清理自己的资源。
- 修复暂停、恢复及连续重启下载时的并发写入与任务生命周期处理，保留断点续传。
- 修复下载完成后刷新主题库时，旧协程结果覆盖新任务状态的问题。

### 验证与下载

- 新增 13 项下载器与任务管理竞态回归测试；PR 的自动化检查、Manager 构建及全部 8 个 KMI 构建通过。
- 附带 Manager APK、16 个双架构 LKM、8 个平台的 ksud，以及 3 个架构的 ksuinit。
- APK 保持相同包名与签名，可覆盖安装 Beta1。LKM 请严格选择与设备架构及 KMI 匹配的文件。
- 仍为预发布版本。本次修复未进行新的真机验证；其他 Beta1 功能及已知限制不变。

## English changelog

This is a theme-download fix release for Beta1 containing PR #4. The original Beta1 release remains unchanged.

### Fixes

- Fix races when restarting a theme download immediately after cancellation: obsolete tasks can no longer overwrite replacement progress, clear replacement state, or publish stale files.
- Isolate staging files and task ownership so each task only cleans up its own resources.
- Fix concurrent writes and lifecycle handling during pause, resume, and repeated restarts while preserving resumable downloads.
- Prevent stale library-refresh results from overwriting replacement task state after download completion.

### Validation and downloads

- Add 13 downloader and job-management race regression tests. PR automation, Manager builds, and all 8 KMI builds passed.
- Include the Manager APK, 16 dual-architecture LKMs, ksud for 8 targets, and ksuinit for 3 architectures.
- The APK retains the same package and signing certificate and can update Beta1 in place. Choose the LKM matching both your device architecture and KMI.
- This remains a prerelease. No additional device validation was performed for this fix; other Beta1 features and known limitations remain unchanged.
