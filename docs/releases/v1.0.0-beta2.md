# LunexSU v1.0.0 Beta2

## 中文更新日志

Beta2 包含 Beta1 Fix 的全部修复，重点改善未安装 Core 时的安装入口可见性。

### 修复与调整

- 当前未安装 LunexSU Core，或 Core 尚未识别 Manager 时，强制使用原生 MIUIX 界面，不再启用主题专用 UI，避免部分主题隐藏安装入口。
- 即使此前安装过 Core 并导入了主题，也以当前检测结果为准；回到前台时重新检测 Core 状态。
- 保留已导入主题和原 UI 偏好，不删除资源、不重写用户选择；重新安装并识别 Core 后自动恢复主题兼容 UI。
- 保留 Beta1 Fix 的下载任务隔离、取消后重新下载、暂停与恢复等竞态修复。
- 清理 LunexSU 仓库继承的上游版本标签，保留 LunexSU 已发布版本；移除仓库 Website 中的 KernelSU.org 链接。

### 验证与下载

- 本地 Release 构建和 214 项 JVM 单元测试通过；Android 测试 APK 已编译。本次变更未进行新的真机验证。
- 附带 Manager APK、16 个双架构 LKM、8 个平台的 ksud，以及 3 个架构的 ksuinit。
- APK 保持相同包名和签名，可覆盖安装 Beta1 或 Beta1 Fix。LKM 必须与设备架构和 KMI 严格匹配。
- 仍为预发布版本，建议备份后使用。主题音效仍不支持，音视频兼容性依赖设备解码器；其他已知限制不变。

## English changelog

Beta2 includes all Beta1 Fix changes and improves access to installation when Core is unavailable.

### Fixes and changes

- Force the native MIUIX interface when LunexSU Core is not installed or has not recognized the Manager. Disable the dedicated theme UI in this state so imported themes cannot hide the installation entry.
- Use the current Core detection result even if Core was installed and a theme was imported previously. Recheck when the app returns to the foreground.
- Retain imported assets and UI preferences without deleting resources or overwriting the user's selection. Restore the compatible theme UI after Core is installed and recognizes the Manager again.
- Retain the Beta1 Fix race corrections for download ownership, cancellation and restart, pause, and resume.
- Remove inherited upstream version tags from the LunexSU repository while preserving published LunexSU releases. Clear the KernelSU.org link from the repository Website field.

### Validation and downloads

- Local Release builds and 214 JVM unit tests passed. The Android test APK compiled; no additional device validation was performed for these changes.
- Include the Manager APK, 16 dual-architecture LKMs, ksud for 8 targets, and ksuinit for 3 architectures.
- The APK retains the same package and signing certificate and can update Beta1 or Beta1 Fix in place. Select the LKM matching both your device architecture and KMI.
- This remains a prerelease. Back up before use. Theme sound effects remain unsupported, media compatibility depends on device codecs, and other known limitations remain unchanged.
