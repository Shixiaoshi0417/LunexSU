# 安全问题报告 / Reporting security issues

LunexSU 基于 KernelSU，上游版权和贡献记录予以保留。涉及本项目包名、
授权有效期、Manager 和移植代码的问题，应向 LunexSU 仓库报告。

请优先使用本仓库的 [GitHub 私密漏洞报告入口](https://github.com/Shixiaoshi0417/LunexSU/security/advisories/new)。
若该入口不可用，请在 [Issues](https://github.com/Shixiaoshi0417/LunexSU/issues)
创建仅包含联络请求的问题，勿公开漏洞利用细节。报告应注明分支、提交、
Manager / Core 版本、设备及复现方式。上游特有的问题可使用
[KernelSU 的报告政策](https://github.com/tiann/KernelSU/blob/main/SECURITY.md)。

LunexSU is based on KernelSU and preserves upstream copyrights and contribution
history. Report issues involving this fork's package identity, authorization
expiry, Manager and ported code to this repository.

Prefer [private GitHub vulnerability reporting](https://github.com/Shixiaoshi0417/LunexSU/security/advisories/new).
If unavailable, open an [issue](https://github.com/Shixiaoshi0417/LunexSU/issues)
requesting contact without publishing exploit details. Include the branch,
commit, Manager/Core versions, device and reproduction steps. Issues specific
to upstream can use [KernelSU's reporting policy](https://github.com/tiann/KernelSU/blob/main/SECURITY.md).
